File: `senllm/modeling_llama.py` unless stated. Line numbers checked on 2026-11-03 and re-checked automatically by the S0.3 gate cell (`notebooks/01_data_eval_views.ipynb`).

1. **Layer loop and `index`**: line 519, `for index, decoder_layer in enumerate(self.layers):`. `index` is the 0-indexed layer number. (Plan v3 §2.2 said line 534; the correct line is 519. Plan corrected in the S0.3 deviation note.)
2. **Replacement statement, before the layer call**: lines 565–568. In the branch `elif index >= layer_index and index < exiting_index:` (565), `previous_sentence_embeddings = hidden_states[:, -1, :].clone()` (567) and `hidden_states[torch.arange(B), pst_token_indices, :] = previous_sentence_embeddings` (568) run **before** `decoder_layer(...)` is called in the same branch. `layer_index = self.tp_starting_index`, `exiting_index = self.tp_exiting_index` (lines 548–549).
3. **Tensor copied**: `hidden_states` at the top of iteration `index` = the input of layer `index` = output of layer `index-1` (or the embeddings when index = 0), last position (`[:, -1, :]`).
4. **Finding `<PST>`**: `find_token_indices` (line 50) asserts every row contains the token (`assert (input_ids == token).any(dim=1).all()`), then returns `argmax` of the boolean mask = first occurrence per row. Called at line 479 for `<PST>` (32000) and line 480 for BOS (1), only when `self.plan == "tp"`.
5. **Hard-coded ids**: 32000 (`<PST>`, lines 50 and 479) and 1 (BOS, line 480). So every TP input must contain BOS id 1.
6. **Extra kwargs in `LlamaDecoderLayer.forward`** (line 336): `pst_token_indices`, `layer_index`, `first_token_indices` are accepted but never used in the body; they are swallowed and passed on as `**kwargs` into self-attention, which does not use them either.
7. **Left padding**: the last position `-1` is always the real last token under left padding (pads are at the front), so the copied state is correct. `find_token_indices` finds `<PST>` per row, so its position may differ per row. `position_ids = cache_position.unsqueeze(0)` (line 502) ignores padding, i.e. padded rows are shifted in absolute position; RoPE attention depends on relative positions only, so this does not change outputs (V10: batched vs batch-1 cosine 0.9999999).
8. **Mask / position ids in plan `tp`**: identical to `vanilla`. The same `causal_mask` (line 504) and `position_ids` are passed to every layer in every branch.
9. **`senllm/utils.py`**: defines its own `scaled_dot_product_attention` and an attention class; it is **not imported** anywhere in `senllm/` or `evaluate.py`, so it is unreachable. The local `scaled_dot_product_attention` in `modeling_llama.py` (line 61) is also not used by the active path: line 330 hard-codes `LLAMA_ATTENTION_CLASSES["sdpa"]`, whose forward calls `torch.nn.functional.scaled_dot_product_attention` (line 299).
10. **Differences from the paper text / side effects**: (a) config `tp_starting_index: 1, tp_exiting_index: 7` gives 6 replacements, before 1-indexed layers 2–7, while the paper text says TP stops "after layer 8" → limitation L4, tested with e = 7 and e = 8. (b) `all_hidden_states += (hidden_states,)` (line 521) is appended before the in-place write at 568, so for `s ≤ index < e` the stored `hidden_states[index]` already contains the copied `<PST>` row; the last-token row (the embedding) is unaffected. (c) The final norm is applied once (line 611) and appended (615), so `hidden_states[-1]` is normed and `hidden_states[27]` is raw. (d) `evaluate.py` seeds only CUDA; on CPU/MPS the `<PST>` row is unseeded.

**Section 5.1 convention**: confirmed. For loop index `i` with `s <= i < e`, the last-token input state is copied into the `<PST>` slot before layer `i` runs; config 1/7 = 6 replacements.
